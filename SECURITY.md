# Security Policy

## Supported Versions

Security fixes are applied to the latest 1.0.x release. Please upgrade to the
newest published version before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.1+  | :white_check_mark: |
| 1.0.0   | :x:                |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security problems.

Report vulnerabilities privately through GitHub's private vulnerability
reporting:

- https://github.com/zilliztech/zilliz-mcp-server/security/advisories/new

If you cannot use GitHub, email **support@zilliz.com** with a subject line
starting with `[SECURITY]`.

Please include:

- A description of the issue and the affected version or commit
- Reproduction steps or a proof of concept
- The potential impact
- Any suggested fix or mitigation

We will acknowledge your report as soon as possible and keep you informed of
our progress. Once a fix is available, we will publish a GitHub Security
Advisory and credit the reporter unless anonymity is requested.

## Scope

This policy covers the `zilliz-mcp-server` package and the code in this
repository. Vulnerabilities in third-party dependencies should be reported to
the respective upstream projects.

## Safe Harbor

We will not pursue legal action against researchers who make a good-faith
effort to follow this policy, avoid privacy violations and service disruption,
and give us reasonable time to remediate before public disclosure.
